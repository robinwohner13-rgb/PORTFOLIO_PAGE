# Robin Wohner portfolio

Open `index.html` locally. Home, Films, Music and Contact are separate static pages; no build step is required.

The home page includes a biography and personal note. Film entries are placeholders to replace with real project credits and stills. Music lists six releases from Robin's Spotify artist page. Contact has email, Instagram, Spotify, Apple Music and YouTube Music links.

See `EDITING.md` for content changes and `images/README.md` for image filenames.
