# Robin portfolio — working draft

Open `index.html` locally. Home, Film, Discography, About and Contact are separate pages. No build step is required.

Put your own images in the `images` folder; its README lists exact filenames. The visible image slots remain until you add the files. Replace the clearly labelled film and release placeholders with actual titles, credits and links. Add your email to `contact.html` before sharing.

This is a new version of the same portfolio file. The dark blue and gray are provisional.
