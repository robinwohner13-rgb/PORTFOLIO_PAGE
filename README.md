# Robin portfolio — working draft

Open `index.html` locally. Home, About, Films, Music, Media and Contact are separate pages. No build step is required.

Put your own images in the `images` folder; its README lists exact filenames. The visible image slots remain until you add the files. Film entries are still placeholders. Music contains the six releases from your Spotify artist page. Contact has your email, Instagram and Spotify links.

This is a new version of the same portfolio file. The dark blue and gray are provisional.
