# Film score audio

Put your own MP3 files here using the filenames `film-01.mp3` and `film-02.mp3`. The players on `film.html` will work as soon as those files are present. Export short, web-ready stereo excerpts rather than full production sessions. Keep the filenames in the HTML in sync if you rename the files.

The film page contains player controls but no audio files yet. Only add music you can publicly share, especially for unreleased films.
