# Your photographs and artwork

Place JPG files here using these exact names, then refresh the page:

- `home.jpg` — landing page portrait or atmosphere image, ideally landscape or tall crop
- `film-01.jpg`, `film-02.jpg` — film stills or posters
- `release-01.jpg`, `release-02.jpg` — square release artwork
- `about.jpg` — portrait or performance photograph

If you use PNG or WebP instead, change the matching filename in the HTML. Add meaningful alt text when you have the actual images. Only use images and film stills you have permission to publish.
