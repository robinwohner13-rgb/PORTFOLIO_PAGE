# Your photographs and artwork

Place your own JPG files here using these exact names, then refresh the page:

- `home.jpg` — landing page portrait or atmosphere image, ideally landscape or tall crop
- `film-01.jpg`, `film-02.jpg` — film stills or posters
- `release-01.jpg`, `release-02.jpg` — square release artwork
- `about.jpg` — portrait or performance photograph
- `media-01.jpg`, `media-02.jpg`, `media-03.jpg` — portraits, performances, or studio photographs for the Media page

If you use PNG or WebP instead, change the matching filename in the HTML. Add meaningful alt text when you have the actual images. Only use images and film stills you have permission to publish.

## Spotify release artwork

The six release covers (`flower.jpg`, `nagori.jpg`, `dream-book.jpg`, `lycaenidae.jpg`, `hotaru.jpg`, `moon-ocean.jpg`) were downloaded from Spotify's public oEmbed thumbnail URLs for the matching releases. They are used in `discography.html`. Keep your rights to display the cover art in mind when publishing outside Spotify.
